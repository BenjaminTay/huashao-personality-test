# 花学测试｜花少人格鉴定

**花学测试**是这里的栏目品牌，本期这款测试的名字就叫**花少人格鉴定**——一份从日常人际关系出发的娱乐人格测试。24 道题，带你从“大家目前都很礼貌”，一路测到“这顿饭到底还能不能好好吃”，最后看看你在《花少 2》的关系现场里，究竟是哪一种花学人格。

不是考节目知识，也不是让你复刻名场面。我们只是想知道：当气氛开始微妙、群聊突然安静、有人说“没事”的时候——你通常会怎么做？

## 你会测到什么

- 你是先观察全场、直接问清楚，还是先把自己的边界画出来？
- 别人情绪不对时，你会立刻接锅，还是决定“这件事不归我管”？
- 一群人意见不一致时，你负责读空气、修罗场收尾，还是优雅退到安全区？
- 关系变复杂以后，你还会继续解释，还是已经准备下线？

题目分成四幕：从轻松寒暄，到空气微妙，再到关系压力上升，最后进入“旅程结束以后，大家还联系吗”的余震现场。

## 你可能是哪一型

| 花学人格 | 关键词 |
| --- | --- |
| 毛阿敏型 | 先看懂局，再决定怎么走 |
| 许晴型 | 关系可以复杂，但话要说真 |
| 宁静型 | 我的边界，我先说清楚 |
| 郑爽型 | 事情出了问题，先问是不是我没做好 |
| 陈意涵型 | 快乐很重要，必要时先保全自己 |
| 井柏然型 | 气氛要是冷了，那就想办法修一下 |
| 杨洋型 | 大家在忙什么？我先把旅行过完 |

测出来的不是“你现实中就是谁”，而是你在这些情境里的默认反应更接近哪种娱乐原型。没测到想要的类型？别急，副型和最不像谁也很有戏。

## 测完你会拿到

- 一个主型：你在关系现场最常站的位置；
- 一个副型：你身上另一套也很熟练的处理方式；
- 一个最不像：你和哪种相处逻辑隔着一整条伦敦地铁线；
- 六维关系属性面板：由你的 24 次选择换算成的展示分，不是概率——留着跟朋友互相伤害用；
- 一条心眼子余额和一份“你可能被误读成”的人格解读；
- 一张可以直接填名字、截图、下载、发给朋友互相对号入座的花学档案卡。

测完还能去“测友坐标”看看：目前已录入的测友人次里，有多少人和你同型。

## 为什么值得测一下

因为很多时候，我们不是不知道发生了什么，而是不知道自己为什么总是在同一个位置上：

有人负责读空气，有人负责把话说开；有人自动开始背锅，有人已经走到门口；还有人全程只想问一句——**“所以今天到底几点出发？”**

花学测试不负责给你下定义，只负责把那些“我怎么又在收拾残局”“我怎么又开始想太多”“我怎么完全没发现有局”的瞬间，做成一份有点准、有点损、但总体很懂你的结果。

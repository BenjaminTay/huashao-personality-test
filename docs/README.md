# 花少人格鉴定｜研究与决策索引

本目录保存项目从互联网调研、节目材料整理、人物原型建模，到题库、计分和结果体验设计的推导过程。

初始材料来自 ChatGPT 会话“花少2人格测试网站”（会话 ID：`6a9845cc-8bb4-83ee-99a0-688a812c067c`），于 2026-09-03 重新梳理。会话本身只作为决策过程记录，不作为外部事实来源；能恢复的公开来源已换成可访问 URL，无法确认的内容进入待核验清单。

它与代码的关系是：

- `data/` 与 `lib/` 是当前可执行真相源；
- `docs/research/` 说明素材来自哪里、哪些结论可靠、哪些仍是解释；
- `docs/decisions/` 说明当前 V3 为什么这样设计，以及哪些旧路线已经废弃；
- `docs/archive/` 只记录历史版本边界，不能作为当前实现输入。

## 使用规则

- 不把娱乐原型写成对现实真人的诊断；
- 不把网友高赞解释写成节目事实；
- 不把名称相似、多人转载或视频可访问当作已经核实；
- 修改冻结内容前，先更新版本号、数据、测试和相关文档；
- 新增事实材料时记录 URL、发布日期、来源层级、支持内容与局限；
- 新增题目时先通过题目质量门禁，再进入评分矩阵。

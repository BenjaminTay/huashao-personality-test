# 历史资料归档说明

本目录只用于保存已经废弃但对理解决策有帮助的材料。

## 已废弃基线

- Question Set V1；
- V2 / V2.1 / V2.4 题库；
- 人物直接加分；
- 用普通六维欧氏距离直接决定最终人格；
- 在题目选项里大量使用系统/KPI/项目经理式比喻；
- 让用户模拟完整参加一次《花少2》旅行的产品方向。

## 归档规则

- 旧题全文如需加入，文件名必须带明确版本和 `DEPRECATED`；
- 归档文件不得被 `data/` 或 UI import；
- 不复制当前 V3 题库到这里；
- 旧版有价值的结论优先提炼进 `docs/decisions/`；
- 只在需要追查决策历史时阅读本目录。

当前实现唯一真相源仍是 `data/` 与 `lib/scoring.ts`。

# Result System v2 梗感改版 与 Question Set v3.2 勘误

> 状态：已批准合入（2026-09-03，产品负责人）。
> 范围：结果层展示文案与页面结构。计分逻辑、评分矩阵（v3.1）、人格坐标（v2.1）、六维语义与 `internalName` 均未变。

## 1. 为什么做

立项决策《结果系统、产品体验与隐私决策》要求结果页"像互联网损友互怼"，但 v1.1 落地时遗留了一批"档案仪器腔"：

- 结果页直接出现"核心算法""YOUR DEFAULT STRATEGY""FIELD READOUT 01/02""3 RECORDS""展示分 / 0—100""本次现场读数"等实现语言；
- 六维卡片裸显示内部代号 R/S/B/D/G/I；
- 六维展示名（"关系占内存""读空气灵敏度"等）拗口、网感不足；
- 缺少《花少 2》名场面金句的"考古回响"位置；
- 决策文档 §2 要求的"心眼子彩蛋 + 档案台词"位置不完整，`recall` 位留空；
- 数据层存在死内容（每型 `profile` 六维文字画像从未被 UI 使用）。

原则：内容上放开玩梗、减少安全腔；但研究规则（research/00）仍要求"未经核验的原话不做经典台词署名"，因此对无法核验的引用以"流传版/非原话/转述"档案语言呈现——考古悬案本身也是梗，不是免责声明。

## 2. 改动清单

### 2.1 题库 Question Set v3.1 → v3.2（文案勘误，矩阵数值未变）

| 位置 | 改动 | 原因 |
| --- | --- | --- |
| Q06 选项 A | "朋友这么介意，会明显影响我之后和TA的关系。" → "朋友这么介意，这件事会开始持续影响我。" | 原句 "TA" 指代歧义（好朋友还是被讨厌的那位），两种读法会测出不同含义 |

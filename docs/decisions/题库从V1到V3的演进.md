# 题库从 V1 到 V3 的演进

## 1. 目标没有变

题库始终服务于同一个目标：用用户熟悉的日常人际情境，观察其在关系暗流、群体压力和冲突余震中的默认策略，再匹配七种娱乐人格原型。

题目不考节目知识，也不要求用户想象自己真的参加《花少2》。节目和网络梗负责气质，真实生活选择负责测量。

## 2. V1 的价值与问题

V1 建立了四幕结构和较强的剧情体验：

```text
大家目前还挺正常
→ 关系开始有点不对劲
→ 修罗场加载
→ 事情过去后的余震
```

它证明了“连续心理压力”比 24 道完全独立的散点题更有产品感。但不少题目带有较长故事、明显网络比喻或预设的人格解释。

## 3. V2 / V2.1 / V2.4 的改进

V2 将场景扩展到朋友、群聊、室友、合作、聚会和旅行，并试图消除“高情商正确答案”。V2.1 对七道薄弱题进行定点修复；V2.4 进一步强化了四幕旅行体验。

当时建立了两层评审框架。

### 单题评审

1. 场景真实度；
2. 情境张力；
3. 人格区分度；
4. 选项等价性；
5. 社会赞许偏差；
6. 维度纯度；
7. 第一反应可回答；
8. 语言自然度和网感；
9. 是否暴露测量目的；
10. 是否与其他题重复机制。

### 整套题库评审

1. 六维覆盖；
2. 七人格 Bright/Shadow 平衡；
3. 四幕节奏；
4. 场景多样性；
5. 重复题比例；
6. 是否容易猜人物；
7. 完成负担；
8. 结果是否能被真实答案解释。

V2 一度被评为约 84/100 的 Beta：真实度、剧情推进和模型骨架已经不错，但仍有少数“成熟答案”，人物获得正负面机会不均，以及题目机制重复。

## 4. 为什么最终不是修成 V2.5

实际试玩后确认，V2.4 的问题不是几句文案，而是四个系统性漂移。

### 4.1 从生活人格测试漂成旅行真人秀模拟

用户回答的是“如果我参加这种旅行可能怎样”，而不是“现实里的我通常怎样”。

### 4.2 从行为选择漂成人格观点选择

选项开始解释自己的成熟性、边界观或人际策略，等于把测量目的提前告诉用户。

### 4.3 Bright / Shadow 失衡

井柏然、陈意涵、宁静、杨洋的一些选择容易显得更健康；许晴、郑爽更容易只获得负面题目。测试暗中变成了价值排名。

### 4.4 大量题目主观上都在测读空气

“都可以”“没关系”“没事”“沉默”“没叫你”“事后吐槽”反复出现。后台维度看似均衡，用户体验仍然重复。

因此决定将 V2.4 视为有价值但失败的原型，重建 `Question Set v3.0`。

## 5. V3 的设计顺序

V3 不从写 24 篇正文开始，而是先设计 24 个“测量瞬间”：

```text
现实中确实可能发生的情境
→ 四种自然但互相冲突的行为
→ 主测两个维度
→ 重点拉开若干相似人格
→ 最后才加入少量花学气质
```

这避免为了给四个人格各安排一个选项而硬凑答案。

## 6. V3 四幕蓝图

### Act 1｜默认模式

观察群体决策、新关系、明确边界、承诺、求助和独立判断。整体平静，让用户先看到日常里的自己。

### Act 2｜关系开始微妙

观察冷淡、“没事”、被忽略、临时取消、关系信号、室友不适和他人矛盾。

### Act 3｜压力上升

集中少量旅行和群体高压：疲劳、资源不足、分配、错误、站队和过度维修。

### Act 4｜关系余震

观察冲突后是否谈清、如何处理长期不适、关系变淡、被误解、是否重新进入旧群体。

真正旅行题约占五道，约为总题量的 20%。旅行感主要通过第三幕和页面包装集中释放。

## 7. V3 强制语言标准

题目要像朋友在问：“这种情况你一般怎么办？”

每题必须做到：

- 一眼读懂，5–10 秒内能凭第一反应作答；
- 选项描述“做什么”，不解释“这说明你是什么人”；
- 四个答案是明显不同的行为，而非细微措辞差别；
- 不出现一个正常成年人理应选择的唯一答案；
- 长度尽量相近，不用篇幅暗示高级答案；
- 避免“成熟、理性、尊重、公平、高效”等直接褒义标签；
- 少用“系统、后台、工单、KPI、项目经理”等 AI 感比喻；
- 网络梗主要放到过场、Loading、结果页和分享卡；
- 不在选项旁展示人格、维度、分数或副作用解释。

## 8. Bright / Shadow 题目平衡

V3 特别补入了此前缺失的正向机制：

- 郑爽型：守承诺、对真实参与的错误愿意承担；
- 杨洋型：尊重明确边界和提前说明，不自动脑补；
- 宁静型：直接求助、表达真实需要；
- 井柏然型：群体失灵时有效组织；
- 陈意涵型：把个人生活从无效 drama 中拿回来；
- 毛阿敏型：识别隐性需求并自然融入新人；
- 许晴型：重要关系出现裂缝时愿意真正面对。

同时每一型都有代价题，例如第三次传话、值得处理却被放掉、明显信号仍按字面理解等。

## 9. 当前冻结边界

当前 V3 的题目 ID、选项 ID、顺序、四幕分组、正文和 24×4 评分矩阵均已冻结。新增研究不应直接改题；应先形成变更提案，说明：

1. 哪条真实用户证据证明现题有问题；
2. 问题属于文案、区分度、评分还是结构；
3. 会影响哪些相似人格；
4. 新版本号是什么；
5. 数据、测试、README 和本文档如何同步。

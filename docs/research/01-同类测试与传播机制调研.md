# 同类测试与传播机制调研

## 1. 产品不是“严肃心理测量网站”

这类产品更适合被理解为一种轻量内容产品：用户通过低门槛选择获得一个有身份感、可自嘲、可截图、可邀请朋友参与的结果。

2026 年 4 月 SBTI 在社交平台刷屏，并因短时间访问激增出现页面不可用。公开报道可参考[澎湃新闻转载报道](https://www.thepaper.cn/newsDetail_forward_32939679)。这个案例对本项目最有价值的不是具体流量数字，而是传播链路：

```text
看到朋友结果卡
→ 好奇自己是什么
→ 无需登录立即答题
→ 得到短而有梗的身份标签
→ 截图或分享
→ 拉朋友一起测
```

部分商业复盘会给出巨大但难以独立验证的阅读量、在线人数和覆盖率，本项目不引用这些数字作为决策依据。

## 2. 会话中归纳出的同类产品类型

| 类型 | 典型吸引力 | 可借鉴点 |
|---|---|---|
| 抽象人格 | 强烈自嘲标签 | 结果名称比理论术语更容易传播 |
| 动物映射 | 可爱、容易视觉化 | 图像识别度和朋友间“认亲” |
| 恋爱人格 | 天然讨论度高 | 结果差异、关系话题、邀请他人 |
| 网络状态标签 | 紧跟新词 | 上线快，但生命周期短 |
| IP/音乐/角色映射 | 圈层精准 | 用户对结果对象已有情感 |
| 测试合集平台 | 长尾流量 | 适合后续引擎化，不属于 V1 |

## 3. 花少人格鉴定的差异化

不能只依赖“你是哪位嘉宾”这个 IP 映射。真正的差异应当是：

- 24 道真实人际情境，而不是 5 道节目知识题；
- 从日常关系逐步进入群体高压和关系余震；
- 六维画像能解释行为倾向；
- 主型、副型、最不像共同提供区分；
- 3 条证据来自用户真实答案；
- 结果同时有高光面和花少 Bug；
- 原创档案视觉让分享卡一眼可识别。

## 4. V1 用户旅程

```text
外部分享卡 / 朋友截图
→ 首页
→ 24 题单题流程
→ 四幕过场
→ 可跳过的鉴定 Loading
→ 主型 Reveal
→ 六维与答题证据
→ 副型 / 最不像 / 花少 Bug
→ 下载分享卡
→ 重测或邀请朋友
```

首页不提前展示七种人格完整图鉴，否则用户可能按目标结果作答。

## 5. 产品门槛

- 无需注册、手机号或微信授权；
- 一屏一题，点击后有明确反馈并在约 200–300ms 后前进；
- 始终能返回修改；
- 清楚显示进度和剩余题量；
- 没看过节目也能理解题目；
- 390px 移动端完整可用；
- 结果卡优先 3:4，并为 9:16 留接口；
- 减少动效设置下不强制等待。

## 6. 数据与运营

V1 不需要收集身份信息或原始答案。若做匿名埋点，最小事件集为：

```text
page_view
start_test
chapter_complete
test_complete
result_type
share_generate
share_click
retake
```

推荐观察：

- 首页到开始的转化；
- 每一幕的退出率；
- 完成率与中位完成时长；
- 七种结果分布是否异常偏斜；
- 分享卡生成率和分享点击率；
- 重测率；
- 移动端错误与加载性能。

`result_type` 可以记录，96 个原始选择不应上传。任何短分享参数也不能携带完整答案。

## 7. 部署与变现边界

V1 是静态前端优先产品，可使用静态托管、对象存储/CDN 或支持 Next.js 的托管平台。上线前优先保证峰值承载、中文字体、分享图生成、路由回退和移动端性能。

潜在变现路径包括品牌定制测试、多个测试组成的内容站、非侵入广告或为 IP/创作者提供测试制作服务。但这些都不应进入 V1 必做范围；过早加入登录、付费、排行榜和复杂广告会直接破坏传播链路。

## 8. 研究局限

同类测试的热度、入口和镜像站变化很快。本文件记录的是产品机制，不维护“全国最火 Top 10”或某个未经确认的唯一官方网站。需要选平台、买域名或正式投放前，应重新做一次当前状态核验。
